# 実装判断メモ

## 目的

`docs/kotonoha-system.md` を実装に落とす前に、決めるべきことを整理するためのメモです。  
短期デモを前提に、まずは「今すぐ決めること」を優先して固めます。

## 使い方

- `状態` は `未決` / `仮決定` / `確定` で更新する
- `推奨案` は、短期実装を進めやすくするためのたたき台
- 迷ったらまず `今すぐ決めること` から埋める

## 現時点のおすすめ短期方針

短期で形にするなら、まずは以下で進めるのが安全です。

1. `Gemini + Supabase + Go/Gin + Next.js` で土台を固定する
2. `モックセンサー` でセンサー連携を先に成立させる
3. `ログイン → 初期設定 → センサー反映チャット` を最初の完成ラインにする
4. `Push` と `RAG` は次フェーズに回す

## 確定したセンサーPOSTたたき台

```json
{
  "device_id": "mock-device-001",
  "recorded_at": "2026-04-13T10:30:00+09:00",
  "moisture_percent": 58,
  "light_lux": 12000,
  "temperature_celsius": 24.3
}
```

- `device_id`: 送信元識別子。モックでも実機でも同じキーを使う
- `recorded_at`: ISO 8601形式の計測時刻
- `moisture_percent`: 0〜100 の整数または小数
- `light_lux`: 照度
- `temperature_celsius`: 摂氏温度
