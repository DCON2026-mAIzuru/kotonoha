# Software

## センサーデータと記憶を統合し、盆栽らしい対話を実現

### センサー値を組み込んだ動的プロンプト
Go バックエンドで Gemini API に渡すプロンプトを生成。
ユーザー発話、盆栽プロフィール、土壌水分、照度、気温を統合し、
現在の状態に応じた返答へ制御する。

### pgvector による長期記憶検索
会話履歴を Supabase PostgreSQL に保存。
Gemini Embedding API で会話内容をベクトル化し、
pgvector で類似する過去の記憶を検索してプロンプトに反映する。

### WebSocket によるストリーミング表示
Gemini のストリーミング応答を Go サーバーで受け取り、
WebSocket でフロントエンドへ逐次送信。
返答の生成途中から表示し、リアルタイムな対話感をつくる。

### センサーイベントと Web Push 通知
ESP32 から送られたセンサー値を Supabase に保存。
水やりや乾燥などの変化を Go 側で検知し、
Gemini で自発メッセージを生成して Web Push 通知に利用する。
